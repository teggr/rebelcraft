## j2html-toolkit

Use j2html to build HTML from typed Java components and layouts.

- [Repository and quick start](https://github.com/teggr/j2html-toolkit#quick-start)
- This showcase's reusable components are in `showcase-plugin`.

## java-html-toolkit

Preview HTML-producing Java methods and publish a browsable component catalog.

- [Repository and `@Preview` guide](https://github.com/teggr/java-html-toolkit)
- The generated catalog is available on the [RebelCraft showcase](../catalog/).

## Electrostatic

Generate a static documentation site from a project-specific content folder.

- [Repository and quick start](https://github.com/teggr/electrostatic#quick-start)
- [GitHub Pages deployment guide](https://github.com/teggr/electrostatic/blob/main/electrostatic-run/src/main/resources/site/_guides/github-pages-guide.md)

## TeaVM

Compile Java application code to JavaScript for client-side behavior.

- [TeaVM getting started](https://teavm.org/docs/intro/getting-started.html)
- The repository explorer demonstrates its browser APIs and Maven compiler.
